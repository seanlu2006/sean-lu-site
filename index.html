CountAgent

A personal expense agent on Claude Code. Siri appends one line of text; the agent later parses, categorises and deduplicates it. My own expenses have run through it since June 2026.

Demo dashboard (sample data)↗ GitHub ↗
Read case notes
Problem
The friction in expense apps is input. Open the app, pick a category, type the amount. Three steps and you quit.
Approach
Capture shrinks to one sentence. The agent handles interpretation later.
Budget
A month runs from the 24th to the 23rd, the credit-card cycle, so the budget matches the bill I actually pay. Quarters are three cycles.
Trade-off
Behaviour lives in CLAUDE.md, in plain language rather than code. Rules change without a code change. The price is non-determinism, so a human review step stays.

Claude Code · Python · A/B testing

Pokémon TCG agent

Played 1,031 ranked matches in the dev.fun Arena and never cracked the top 10. The useful part was learning which results to ignore.

  • 1,031ranked matches
  • 481wins
  • 62ndbest rank, of about 123 agents
  • 56,743replayed decisions in the test suite
Problem
The engine is closed, hands are hidden, and the deck locks for the whole season. Every experiment costs ranked games.
Found
Batch win rates were noise. Two versions making the same moves still finished 11 points apart over 155 games.
Trade-off
The turn planner only overrides the old rules when a line takes more prizes this turn or avoids losing next turn. Given every decision, it agreed with strong players less often.
Role
I made the calls: the deck, the switch to A/B tests, the planner, when to stop. Claude Code wrote the code.

vid-for-agents

One command turns video into sampled frames and a local transcript that coding agents can read.

Problem
Agents read text. Video tutorials and screen recordings are a black box.
Approach
Reduce video to two things an agent can read: frames and text.
Trade-off
Speech-to-text runs locally on whisper.cpp. Slower, but no key, no upload, $0.

IELTS Desk

A Traditional Chinese IELTS study desk. Vocabulary, Leitner review, AI mock questions, a mistake notebook and writing feedback, all in the browser.

Problem
Existing IELTS tools cost money, require an account, and keep your data.
Approach
Everything runs in the browser. Data exports as JSON; cloud sync is optional.
Trade-off
No backend, so server cost is zero and users bring their own Gemini key. Leitner instead of SM-2, because you can see which box a word is in.
