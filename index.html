Trade journal

My own trading journal, built to stop paying for TradeZella. It follows TradeZella's pages and workflow, holds my trade history, and adds a replay for practising entries on past gold prices.

The code stays private because my trade data lives next to it.

  • 114trades moved over from TradeZella
  • 7 / 7dashboard stats match TradeZella's
  • 26strategy rules, each rule's stats match too
  • 1 minsmallest replay step, on Dukascopy prices
Problem
I liked TradeZella's workflow, not paying a subscription for one account's trades.
Approach
Same pages, flow and terms, on a local SQLite file. A check script compares every number with TradeZella's export.
Replay
Market, limit and stop orders, SL and TP dragged on the chart, size from risk. If one minute touches both SL and TP, it counts as a stop.
Trade-off
Dukascopy candles differ slightly from my broker's, and there is no futures data yet.
Role
I wrote the spec from daily use and checked the numbers. Claude Code wrote the code.

CountAgent

I quit every expense app within two weeks. This one stuck: capture is one line to Siri, and the AI only comes in after capture, to parse, categorise and catch duplicates. 454 entries since June 2026.

Capture
One sentence to Siri appends a line to a text file. No app to open, no category to pick.
Duplicates
The same amount and meaning on the same day goes in once. The agent asks instead of guessing.
Month
A month runs from the 24th to the 23rd, the card cycle, so the budget matches the bill I pay.
Trade-off
Rules live in plain language in CLAUDE.md, not code. Easy to change, not deterministic, so a human review step stays.

Pokémon TCG agent

Played 1,031 ranked matches in the dev.fun Arena and never cracked the top 10. The useful part was learning which results to ignore.

  • 1,031ranked matches
  • 481wins
  • 62ndbest rank, of about 123 agents
  • 56,743replayed decisions in the test suite
Problem
The engine is closed, hands are hidden, and the deck locks for the whole season. Every experiment costs ranked games.
Found
Batch win rates were noise. Two versions making the same moves still finished 11 points apart over 155 games.
Trade-off
The turn planner only overrides the old rules when a line takes more prizes this turn or avoids losing next turn. Given every decision, it agreed with strong players less often.
Role
I made the calls: the deck, the switch to A/B tests, the planner, when to stop. Claude Code wrote the code.
