讀設計筆記Read case notes
問題Problem
市面 IELTS 工具要付費、要帳號、資料不在自己手上。
Existing IELTS tools cost money, require an account, and keep your data.
解法Approach
全部跑在瀏覽器。API key 存 localStorage，資料可匯出 JSON，雲端同步是選配。
Everything runs in the browser. The API key lives in localStorage, data exports as JSON, and cloud sync is optional.
取捨Trade-off
Gemini 直接從瀏覽器呼叫，沒有自己的後端。伺服器成本是零，代價是使用者得自己申請 key。複習演算法用 Leitner 不用 SM-2，因為使用者看得懂自己在第幾盒。
Gemini is called from the browser with no backend. Server cost is zero; users bring their own key. Leitner replaces SM-2 because each box is easy to understand.
學到Learned
動態抓模型清單，比把模型名稱寫死耐用。另外寫了一份給 Claude Code 的交接包，之後再迭代就不必從頭交代專案。
Dynamic model discovery outlasts hardcoded model names. A Claude Code handoff package means later iterations do not start from zero.

vid-for-agents

一行指令把任何影片變成取樣畫格與本地逐字稿，讓 AI coding agent 能「看」影片。

One command turns video into sampled frames and a local transcript that coding agents can read.

問題Problem
Agent 只能讀文字。影片教學、螢幕錄影對它們是黑盒。
Agents read text. Video tutorials and screen recordings are a black box.
解法Approach
把影片拆成 agent 讀得懂的兩種東西：畫格和文字。
Reduce video to two things an agent can read: frames and text.
取捨Trade-off
語音辨識跑本地 whisper.cpp。慢，但不用 key、不上傳、$0。
Speech recognition runs locally with whisper.cpp. Slower, but no key, upload or API cost.

Claude Code · Python · iOS Shortcuts

CountAgent

跑在 Claude Code 上的個人記帳 agent。Siri 往檔案追加一行純文字，agent 之後負責解析、分類、去重。

A personal expense agent on Claude Code. Siri appends one line of text; the agent later parses, categorises and deduplicates it.

問題Problem
記帳 app 的摩擦在輸入。開 app、選類別、填金額，三步就放棄。
The friction in expense apps is input: open the app, choose a category, enter the amount.
解法Approach
輸入端只剩一句話，理解交給 agent 批次處理。
Capture shrinks to one sentence. The agent handles interpretation later.
取捨Trade-off
行為寫在 CLAUDE.md 裡。改規則不用動程式碼。代價是行為不完全確定，所以保留人工審核。
Behaviour lives in CLAUDE.md, so rules change without code. Non-determinism remains, so human review stays.
