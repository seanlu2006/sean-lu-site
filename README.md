# sean-lu-site

My personal site: [sean-lu.pages.dev](https://sean-lu.pages.dev)

One HTML file. No build step, no dependencies, no framework — `index.html` plus two image files.
Bilingual (正體中文 / English) via a CSS class toggle and ~15 lines of vanilla JS.

Deployed on Cloudflare Pages; every push to `main` publishes automatically.
