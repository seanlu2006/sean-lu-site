# sean-lu-site

My personal site: [sean-lu.pages.dev](https://sean-lu.pages.dev)

Plain HTML, CSS and a little vanilla JS. No build step, no framework, no dependencies.
Bilingual (正體中文 / English), light and dark mode, and it respects `prefers-reduced-motion`.

Deployed on Cloudflare Pages; every push to `main` publishes automatically.
